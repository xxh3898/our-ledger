# 자산 화면

## 상단 지표

- 총자산
- 총부채
- 순자산

## Account 그룹

- 치호 개인
- 여자친구 개인
- 공동

각 Account는 현재 잔액, type, institution, archive 여부를 표시한다. 신용카드는 양수 미결제 부채를 화면에서 음수 또는 “부채” label로 명확히 표현한다.

## 자산 추이

월말 기준 순자산 추이를 제공한다. 과거 거래 수정 시 과거 월 값도 재계산될 수 있다는 점을 일관되게 처리한다.

## 결혼자금 카드

- 목표액
- 현재 보유금
- 누적 마련금
- 목표 관련 사용액
- 달성률
- 최근 월평균 순저축
- 예상 달성 시점

카드 클릭 시 Goal 상세로 이동한다.

## Account 관리

생성, 수정, 정렬, archive. 전체 계좌번호 입력란은 제공하지 않는다.
