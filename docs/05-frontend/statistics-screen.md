# 통계 화면

## 범위

- 수입
- 순소비
- 저축
- Category별
- 개인·공동별
- Account별
- 월별 추이
- 전월 비교

## 기간

이번 달, 지난달, 최근 3개월, 최근 6개월, 1년, 직접 선택.

## 원칙

- backend 계산을 기준으로 한다.
- frontend가 별도 합계를 재구성해 다른 숫자를 만들지 않는다.
- 모든 주요 숫자는 해당 조건 거래 목록으로 이동 가능해야 한다.
- 지난 기간 값이 0이면 잘못된 무한대 증감률을 표시하지 않는다.

## 시각화

차트보다 숫자와 비교 가능한 표를 우선한다. 모바일에서 범례와 label이 잘리지 않아야 한다. Category가 많으면 상위 항목과 기타를 구분하되 원본 조회는 가능해야 한다.

## 필터

전역 주체 필터와 기간을 기본으로 하며 거래 유형에 따라 부적절한 filter를 숨긴다. 필터 상태는 URL에 유지한다.
