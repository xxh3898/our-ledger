# 달력 화면

## 구성

1. 월 이동과 현재 월
2. 전역 주체 필터
3. 월 수입·순소비·저축 요약
4. 월 달력
5. 선택일 거래 목록
6. 결혼자금 간단 카드

## 날짜 셀

- 일자
- 일별 순소비 또는 수입·소비 요약
- 오늘 표시
- 선택 상태
- 거래 존재 여부
- 무지출일 표시

작은 화면에서 금액이 과도하게 겹치지 않도록 상세 수치는 선택일 목록에 둔다.

## 상호작용

- 이전/다음 월 버튼 필수
- swipe는 보조 기능이며 버튼을 대체하지 않음
- 날짜 선택 시 같은 화면 아래 거래 목록 갱신
- 요약 금액 클릭 시 해당 조건의 거래 목록으로 이동
- URL에 월과 필터를 보존

## 상태

- 로딩 skeleton
- 거래 없음
- 월 aggregate 실패
- 선택일 목록 실패를 분리
- 삭제·수정 후 aggregate와 목록을 함께 무효화

## 접근성

달력은 시각적 grid뿐 아니라 날짜 button의 접근 가능한 이름과 선택 상태를 제공한다. 색상만으로 수입·지출을 구분하지 않는다.
