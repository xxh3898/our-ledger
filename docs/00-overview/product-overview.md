# 제품 개요

## 문제

두 사람이 결혼을 준비하면서는 공동지출만이 아니라 각자의 수입, 개인 소비, 부채, 저축 속도까지 함께 봐야 한다. 일반 개인 가계부는 소유자와 공동 범위를 표현하기 어렵고, 정산 앱은 빚 계산에 집중해 장기 재무관리와 맞지 않는다.

## 해결책

하나의 `Household` 안에서 두 사용자가 다음을 함께 관리한다.

- 각자의 수입과 개인 소비
- 공동 소비
- 개인·공동 계좌와 신용카드
- 월 예산
- 자산, 부채, 순자산
- 저축과 결혼자금 목표

## 핵심 사용자

- 재무 정보를 상호 공개하기로 합의한 두 사람
- 공동 목표를 위해 장기적으로 저축하려는 커플
- 정산보다 전체 현금흐름 관리가 중요한 사용자

V1은 범용 다인 가구 제품이 아니라 **2인 사용 정책**을 전제로 한다. 데이터 구조는 확장 가능하게 두되 서비스 계층에서 Household 구성원을 최대 2명으로 제한한다.

## 핵심 흐름

```text
수입 기록
→ 개인·공동 소비 기록
→ 예산과 소비 구성 확인
→ 잔여 자금을 저축계좌로 이체
→ 결혼자금과 순자산 증가 확인
```

## 가치 제안

- 일반 거래는 몇 초 안에 입력한다.
- 달력과 필터로 원하는 관점에서 소비를 본다.
- 카드대금과 계좌이체를 중복 소비로 계산하지 않는다.
- 목표 금액을 별도 장부에 다시 입력하지 않는다.
- 두 사람이 같은 계산 기준을 본다.

## 성공 기준

V1의 성공은 외부 사용자 수가 아니라 실제 두 사용자가 지속적으로 사용할 수 있는지로 평가한다.

- 주간 기록 누락 없이 사용 가능
- 월 수입·소비·저축·순자산 계산이 수동 검산과 일치
- 개인·공동 소비를 한 번의 필터 전환으로 확인
- 카드 사용과 카드대금 납부가 중복 집계되지 않음
- 결혼자금 현재 보유금과 연결 계좌 잔액이 일치
- 모바일 PWA에서 핵심 거래 입력이 불편하지 않음

## V1 비목표

은행·카드 자동연동, 영수증 OCR, 투자 시세, AI 조언, 네이티브 앱, 다인 가구, 오프라인 쓰기 동기화는 포함하지 않는다.
