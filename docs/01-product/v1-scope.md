# V1 범위

## MUST

| 영역 | 기능 |
|---|---|
| 인증 | 두 사용자 로그인, 세션 유지, 로그아웃 |
| Household | 단일 2인 재무 공간, 구성원 조회 |
| 거래 | 수입·지출·이체, 수정, 논리삭제 |
| 귀속 | 개인 Owner, 공동 Scope, 지출 Payer |
| 환불 | 전체·부분 환불, 원 거래 연결 |
| 계좌 | 입출금, 저축, 현금, 신용카드, 기타 |
| 카테고리 | 그룹, 생성·수정·보관·정렬, icon/color key |
| 조회 | 월 달력, 일별 내역, 조합 필터, 검색 |
| 예산 | 월 전체·개인·공동·카테고리 예산 |
| 반복거래 | 일·주·월·연 단위 자동 거래 생성 |
| 통계 | 기간별, 카테고리별, 주체별, 계좌별, 전월 비교 |
| 자산 | 자산·부채·순자산과 월 추이 |
| Goal | 결혼자금, 계좌 연결, 달성률·예상 달성일 |
| 데이터 | CSV 내보내기, 서버 백업·복구 |
| PWA | 홈 화면 설치, 모바일 우선 반응형 |

## SHOULD

- 무지출일과 연속 무지출 표시
- 최근 입력값을 활용한 빠른 입력 기본값
- 예산 사용률 경고
- 반복거래 사전 확인 화면
- 사용자 지정 탭 순서

`SHOULD`는 MUST를 지연시키거나 복잡하게 만들면 V1 이후로 이동한다.

## OUT

- 은행·카드사 자동 연동
- OCR 영수증 인식과 영수증 원본 보관
- AI 소비 진단·추천
- 투자자산 시세와 평가손익
- 다중 통화·환율
- 카드 할부 회차 상세
- 네이티브 iOS/Android 앱
- 오프라인 쓰기와 충돌 병합
- 푸시 알림
- 다인 가구·조직 회계
- 커플 소비 경쟁·랭킹

## 범위 변경

MUST 추가 또는 OUT 기능의 조기 도입은 새 Issue만으로 결정하지 않는다. 제품 범위 문서 수정과 영향 분석이 필요하다.
